# Security Policy

## Supported versions

The latest release is supported. Older versions are not.

## Reporting a vulnerability

This is a single-player game that reads no network input and writes no files
outside a path you pass it, so the attack surface is small. If you do find
something, please report it privately rather than opening a public issue:

- Use GitHub's [private vulnerability reporting](https://github.com/abedegno/gorilla-rust/security/advisories/new), or
- Email jon@jonwilliams.org.uk

Please include what you did, what happened, and what you expected. You can
expect an acknowledgement within a week.
